\# TPI - Automatización del Proceso de Solicitud de Vacaciones mediante Chatbot



\## Integrantes



\* Francisco Diez

\* Sebastián Colazo 





\## Descripción



El presente proyecto tiene como objetivo automatizar el proceso de solicitud y aprobación de vacaciones de la empresa DistriSur Logística S.A. mediante un chatbot.



La solución propuesta modela el proceso utilizando BPMN 2.0 y simula la interacción con una base de datos para validar saldos de vacaciones, registrar solicitudes y gestionar aprobaciones.





\## Tecnologías Propuestas



\* Python

\* Telegram Bot API (simulado)

\* Excel como base de datos simulada

\* BPMN 2.0 para modelado de procesos





\## Estructura del Proyecto



\* docs/: documentación y diagramas BPMN.

\* data/: base de datos simulada.

\* src/: código fuente.

\* tests/: pruebas y casos de uso.

\* images/: imágenes utilizadas en la documentación.





\## Funcionalidades



\* Consulta de saldo de vacaciones.

\* Solicitud de días.

\* Validación automática.

\* Gestión de aprobaciones.

\* Manejo de errores de entrada.

\* Actualización automática del saldo disponible.
